How it works

Three commands from clone to production

1 · Run it

docker compose up --build
# or: pip install "timesfm3[serve]" && timesfm3 serve

CPU-first, ~1 GB image, health-checked, bundled 5.2M-parameter starter model. No BigQuery, no $12k/month.

2 · Prove it on your data

timesfm3 backtest sales.csv \
  --context 256 --horizon 24

Walk-forward, cluster-bootstrap CIs, HAC Diebold–Mariano with Holm correction. Verdicts: better / no difference / worse.

3 · Make it yours

timesfm3 finetune sales.csv \
  --out sales-v1.pt --steps 300

Fine-tunes on the first 80%, validates on the rest, and prints the same backtest for base vs fine-tuned vs classical.

Quantile bands

Point + q10…q90 per series and step; covariates known ahead of time steer the forecast.

Anomaly detection

/v1/anomalies scores every point against the forecast made before it was seen.

Volatility & sizing

HAR + RiskMetrics variance forecasts and vol-targeted weights for risk desks.

Metered keys

Plans, monthly quotas, usage headers, /v1/usage, Prometheus metrics, OpenAPI.

FAQ

Straight answers

Is this Google's TimesFM-3?

No. It is an independent Apache-2.0 implementation of the architecture Google described, with weights we trained ourselves. Google's own weights, released 31 August 2026, are licensed for non-commercial, non-production use only. Ours can be used commercially. We are not affiliated with Google.

How good is the bundled model?

Small (5.2M parameters, trained on CPU on public data) and honestly benchmarked above: lowest error on held-out data, not yet statistically significant. Run timesfm3 backtest on your series; if the verdict is "no difference", use the free EWMA baseline — we will have told you first. Larger checkpoints are the Enterprise tier.

Does my data leave my perimeter?

On this site, never: the dashboard at /app runs the model in your browser with WebAssembly, and the edge API for classical models keeps nothing. Self-hosted: never. The hosted tiers run the same container behind this Cloudflare edge; requests are metered, not stored.

What about Chronos, Granite, TimeGPT, BigQuery AI.FORECAST?

Chronos and Granite are good Apache-licensed models; this is the service layer around a model, and the registry can serve other checkpoints. TimeGPT starts around $12k/month and is closed. BigQuery needs your data in BigQuery. See the market map.
