API on the free edge

This deployment runs entirely on Cloudflare's free tier. The classical forecasters answer at the edge in JavaScript; the TimesFM-3 model runs in your browser at /app (nothing is uploaded). The self-hosted service (docker compose up) exposes the same endpoints with the neural model server-side, API keys, metering, volatility forecasts and OpenAPI docs.

Forecast

curl -s -X POST /v1/forecast -H 'content-type: application/json' \
  -d '{"targets":[{"name":"sales","values":[12,15,14,18,21,19,24,27,25,30,33,31]}],
       "horizon":4,"model":"ewma","timestamps":["2024-01-01","...","2024-01-12"]}'

Returns forecasts[].point and forecasts[].quantiles.q10…q90, future timestamps when you pass context timestamps (spacing inferred, or set "freq":"D"), and latency_ms. Models: last-value, ctx-mean, drift, ewma (default), ar1, ar4.

Backtest

curl -s -X POST /v1/backtest -H 'content-type: application/json' \
  -d '{"series":[{"values":[...]}],"context":96,"horizon":24,"windows":10,"models":["ewma","ar4"]}'

Walk-forward, non-overlapping windows; per model: mean loss, ratio vs last-value, cluster-bootstrap 95% CI, HAC Diebold–Mariano p-value with Holm correction, win rate, effective sample size, verdict.

Anomalies

curl -s -X POST /v1/anomalies -H 'content-type: application/json' \
  -d '{"series":[{"name":"cpu","values":[...]}],"model":"ewma","context":96,"block":24,"threshold":2}'

Each point is scored against the forecast made before it was seen; score = 1 is the q10/q90 band edge, so 2 is roughly 2.6σ for a Gaussian band.

Limits

30 requests per minute per IP. Requests over the size limits above return 413; asking the edge for the TimesFM-3 model returns 400 pointing at /app. Errors are {"detail": "..."}.
